# 电视直播

一款适用于 **Android TV / 手机** 的电视直播 App。三播放内核可切换、四种直播源格式通吃、支持节目单和回看，播放界面干净清爽。

## 下载安装

1. 点击上面的 **下载最新版 APK**（或打开 [Releases 页面](https://github.com/qqbn2020/LiveTV/releases)，在最新版本下点击 `LiveTV.apk`）；
2. 把 APK 拷贝到电视盒子 / 手机（U 盘、微信文件传输、局域网均可）；
3. 在设备上点击安装（电视上用文件管理器打开），如提示"未知来源"允许即可；
4. 打开 App，按弹窗提示进入设置，添加你的直播源地址即可开始观看。

> 版本发布后由 GitHub Actions **自动构建并挂到 Release**，上述直链永远指向最新版。APK 约 60 MB（内置三套播放内核），支持 Android 5.0 及以上、TV 盒子与手机通用。

## 核心功能

### 播放

- **三内核自由切换**（设置 → 播放设置 → 播放内核）：
  - ExoPlayer — 系统硬解，HLS / DASH / RTMP / RTSP，支持**直播时移**（暂停、±30 秒、拖动进度、回到直播）；
  - IJKPlayer — FFmpeg 解码，软解 / 硬解可切；
  - libmpv — FFmpeg + libass，软字幕能力最强；
  - 内核切换后自动重载当前频道，上层功能（回看、EPG、弹幕）与内核无关。
- **线路降级**：同一频道多个地址，播放失败自动切下一条，全部失败重试一次。
- **画面比例**：适应 / 拉伸 / 裁剪；缓冲时长、解码方式（硬解优先 / 软解）可调。
- **干净的播放界面**：全屏只显示视频画面，频道信息按 INFO 键临时呼出、6 秒自动消失，无常驻时钟 / 提示条 / 转圈。

### 直播源（四种格式自动识别）

| 格式 | 说明 |
| --- | --- |
| M3U / M3U8 | 支持台标、频道号、UA / Referer 请求头、catchup 回看属性 |
| TXT | `名称,地址` 一行一个，`分组,#genre#` 分组，`#` 拼接多线路 |
| XML（TVBox） | `<channels>` 分组 / 频道结构 |
| JSON（FongMi） | `lives` / `groups` 结构，子源递归合并 |

- 多源管理：保存、切换、编辑、删除、刷新；支持网络地址、本地文件；
- 深链一键加源：`livetv://add?url=...&name=...&epg=...`（浏览器、二维码均可触发）；
- 需要外置运行时（jar/js/py）的源无法执行，会跳过并提示。

### 节目单与回看

- **EPG 节目单**：标准 XMLTV，显示当前 / 下一档节目与进度条；
- **回看 Catchup**：支持 `{utc}` / `{utcend}` / `{(b)格式}` / `{(e)格式}` / `catchup-replace` 等模板，节目单里点击已结束节目即可回看；
- 长按 OK（TV）或长按频道（手机）打开节目单。

### 其他

- **频道面板**：分组 / 频道 / 多线路，频道收藏（虚拟「收藏」分组）、频道搜索、分组长按隐藏；
- **直播弹幕**：源里带弹幕地址的频道（B 站 XML / JSON 格式）自动滚动弹幕，可开关；
- **局域网播放页**：手机 / 电脑浏览器访问 `http://电视IP:8899` 直接看，`/playlist.m3u` 可导出到其他播放器；
- **TV 遥控器完整适配**：上下切台、左右 / OK 开面板、数字选台、菜单键进设置、开机自启可开关；
- **手机触屏适配**：单击呼出面板、上下滑切台、双击工具栏、长按频道菜单。

## 快速上手

1. **添加直播源**：设置页 →「添加直播源」，填入名称和地址（网络 URL 或本地文件），EPG 地址可选；
2. **看节目**：上下键 / 滑动切台，OK / 单击开面板选台；
3. **切换内核**：设置 → 播放设置 → 播放内核，遇到播放不了的频道换一个内核试试。

### 遥控器按键

| 按键 | 作用 |
| --- | --- |
| 上 / 下 | 切换频道 |
| 左 / 右 / OK | 打开频道面板 |
| 长按 OK | 当前频道节目单（含回看） |
| 菜单键 | 设置 |
| 数字键 | 频道号跳台（1.5 秒自动跳转） |
| INFO | 临时显示频道信息，6 秒自动隐藏 |
| 返回 | 关闭面板 → 双击退出 |

## 自行构建

```bat
set JAVA_HOME=C:\path\to\jdk-17
gradlew.bat assembleDebug
```

需要 JDK 17 + Android SDK Platform 34（Android Studio 打开也会自动配置）。产物在 `app/build/outputs/apk/debug/app-debug.apk`。

**自动构建**：仓库自带 `.github/workflows/release.yml`，推送 `v*` 标签即自动跑单测、构建 APK 并创建 Release 挂载 `电视直播.apk`；也可在 Actions 页面手动触发。

## 常见问题

- **解析不到频道**：确认地址可访问；TXT 源必须有 `分组,#genre#` 行；编码支持 UTF-8 / GBK。
- **没有节目单**：源未配 EPG，或频道 `tvg-id` 与 EPG 不匹配；可在设置里为源补填 EPG 地址。
- **播放失败**：多为源失效或需要特定 UA / Referer；可在源里设置 UA，或换播放内核再试。
- **时移不可用**：直播时移仅 ExoPlayer 内核 + HLS 流支持；其他内核 / 格式会自动回退普通直播。
